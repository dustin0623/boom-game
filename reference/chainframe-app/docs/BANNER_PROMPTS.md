# Chainframe — Profile Banner Image Prompts

Use Chainframe as the game name and CHAINFRAME for any intentional wordmark. Preserve the existing cosmetic catalog and Soul Studio attribution; invent no handles or domains. Final brand artwork prompts, source constraints and icon derivatives are documented in [ASSET_PROMPTS.md](ASSET_PROMPTS.md#chainframe-brand-artwork). Profile banners remain cosmetic artwork and do not change gameplay.

AI-generated pixel art banners for player profile pages.
Recommended output size: **1200 x 400 px** (3:1 ratio).
Recommended tool: ChatGPT (DALL-E 3) or Midjourney.

## Usage Notes

- Generate at **1200 x 400 px** for best fit as a profile banner.
- Use **PNG** format for clean pixel edges — avoid JPEG compression artifacts.
- If DALL-E softens the pixel art, add: `"no blurring, no smoothing, hard-edged pixels only"` to the prompt.
- For Midjourney append `--ar 3:1 --style raw --no blur` to each prompt.
- Store generated files in `public/banners/` named `banner-01.png` through `banner-25.png`.
